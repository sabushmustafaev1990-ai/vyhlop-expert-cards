## Как перерисовать картинки

```
cd ~/Desktop/Выхлоп-Эксперт
node brand/render.js                      # тексты из data/cards.json, данные из data/firma.json
.venv/bin/python brand/publish_images.py  # копия с латинскими именами в cards-public/
cd cards-public && git add -A && git commit -m "новые картинки" && git push
```

Картинки лежат в публичном репозитории `sabushmustafaev1990-ai/vyhlop-expert-cards` — Яндексу нужна прямая https-ссылка, локальный файл в прайс не вставить.

## Как пересобрать и перезалить прайс

```
cd ~/Desktop/Выхлоп-Эксперт
.venv/bin/python data/build_price.py      # правится в data/build_price.py
```

Потом в кабинете: Товары и услуги → Загрузить XLS/YML → `data/прайс-для-яндекса.xlsx`.
Внимание: новая загрузка **полностью стирает** предыдущий список.

Ограничения Яндекса, на которые уже наступили: колонки строго как в `data/шаблон-яндекса.xls`; «шт» в единицах измерения не принимается; «популярных» товаров максимум 10; позиция с ценой 0 не публикуется (поэтому у заглушек стоит 1 ₽).
